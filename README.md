# CHOCOLATE — Витрина бутика женской одежды (г. Караганда)

Публичный репозиторий интернет-магазина для покупателей.

## Особенности
- **Премиальный минималистичный дизайн**: quiet luxury эстетика, отсутствие лишнего визуального шума.
- **Поддержка PWA**: сайт можно установить на главный экран iPhone (Safari) и Android (Chrome) как мобильное приложение.
- **Полная адаптивность**: корректное отображение на всех устройствах, исключено случайное масштабирование при вводе данных.
- **Заказ в 1 клик через WhatsApp** (+7 701 353 01 15) с авто-формированием состава заказа, выбранного размера (XS-XXL) и адреса доставки.
- **Интеграция с бутиками Караганды**: ТЦ «Арбат» (бутик 1) и ТД «Абзал» (бутик 93), поддержка Kaspi QR и Kaspi RED.

## 🚀 Как выложить на GitHub Pages (Инструкция)

1. Создайте **публичный репозиторий** на GitHub (например, `chocolate-shop`).
2. Загрузите все файлы из этой папки в репозиторий.
3. В настройках репозитория:
   - Перейдите в **Settings** -> **Pages**.
   - В разделе **Branch** выберите `main` (или `master`) и папку `/ (root)`.
   - Нажмите **Save**.
4. Через 1 минуту ваш сайт станет доступен по адресу:
   `https://<ваш-логин>.github.io/<имя-репозитория>/`

## 🔗 Как связать витрину с админ-панелью сотрудников

В файле `js/app.js` на строке 15 есть переменная:
```javascript
const BACKEND_URL = ''; // Например: 'https://chocolate-admin.onrender.com'
```

* **Если админка развернута на сервере (Render / Railway / VPS):**
  Просто укажите адрес вашего сервера админки в `BACKEND_URL`. Витрина будет автоматически загружать актуальные товары и фотографии, добавленные сотрудниками.
* **Если сервер временно не запущен:**
  Витрина автоматически читает файл `products.json` в корне репозитория.
